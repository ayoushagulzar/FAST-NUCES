# Programming Fundamentals – Theory

This directory contains the theory assignments completed as part of the **Programming Fundamentals** course at **FAST NUCES Karachi**. Each assignment is organized in its own folder and includes a dedicated README with detailed information about its contents.

## Assignments

### Assignment 01 – Decision Making & Problem Analysis
Introduces problem analysis using PAC and IPO charts, followed by algorithm design and implementation in C.

### Assignment 02 – Arrays, Functions & Bitwise Operations
Focuses on modular programming using arrays, functions, menu-driven applications, and bitwise operations.

### Assignment 03 – Recursion, Structures, Pointers & File Handling
Covers advanced C programming concepts including recursion, structures, pointers, dynamic memory allocation, and file handling.

> **Note:** Refer to the README inside each assignment folder for detailed descriptions, topics covered, learning outcomes, and implementation details.
