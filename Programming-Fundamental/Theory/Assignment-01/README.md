# Assignment 01 – Decision Making & Problem Analysis

This assignment focuses on problem analysis, algorithm design, and implementing decision-based programs in C. It introduces the process of analyzing problems using PAC and IPO charts before designing algorithms, pseudocode, and finally implementing the solutions.

## Contents

- **Assignment1.docx**
  - PAC Charts
  - IPO Charts
  - Analysis for Questions 1–5

- **C Source Files**
  - C implementation of each question
  - Algorithm (included as comments)
  - Pseudocode (included as comments)

## Topics Covered

- Problem Analysis (PAC & IPO Charts)
- Algorithm Design
- Pseudocode
- Decision Making (`if`, `if-else`, nested `if`)
- Conditional Logic
- Basic Input & Output

## Tasks

### Question 01 – Bank Fraud Detection System
- Detect suspicious banking transactions using multiple conditions.

### Question 02 – Quadrant Identifier
- Determine the quadrant of a point using Cartesian coordinates.

### Question 03 – Driving License Eligibility System
- Decide an applicant's eligibility based on age and test results.

### Question 04 – Poker Full House Detector
- Determine whether a given poker hand is a full house.

### Question 05 – Number Occurrence Counter
- Count the frequency of digits entered by the user.

### Question 06 – Conditional Logic Trace
- Analyze the execution of a given conditional code segment.

## Learning Outcomes

- Analyze problems using PAC and IPO charts.
- Design algorithms, flowcharts, and pseudocode before implementation.
- Apply decision-making using `if`, `if-else`, and nested `if` statements.
- Solve real-world problems using conditional logic.
- Convert problem analysis into structured C programs.

> **Note:** The PAC and IPO charts are provided in **Assignment1.docx**. Each C source file also includes its corresponding algorithm and pseudocode as comments.
