# Assignment 03 – Recursion, Structures, Pointers & File Handling

This assignment focuses on solving real-world problems using recursion, structures, pointers, dynamic memory allocation, and file handling while building modular C applications.


## Topics Covered

- Recursion
- Structures
- Arrays of Structures
- Functions
- Pointers
- Dynamic Memory Allocation
- Memory Management
- File Handling
- Binary Files
- String Manipulation
- Menu-Driven Programming

## Tasks

### Question 01 – Loan Repayment Calculator
- Calculate and display a loan repayment schedule using recursion.

### Question 02 – Spacecraft Fuel Simulation
- Simulate spacecraft fuel consumption and regeneration using recursion.

### Question 03 – Employee Management System
- Manage employee records using structures and user-defined functions.

### Question 04 – Library Shelf Management System
- Implement a limited-capacity library shelf using structures and pointers.

### Question 05 – Line-Based Text Editor
- Build a lightweight text editor using dynamic memory allocation and file handling.

### Question 06 – IEEE/ACM Membership Registration Manager
- Develop a file-based student membership management system.

## Learning Outcomes

- Implement recursive solutions for sequential problems.
- Design programs using structures and arrays of structures.
- Use pointers for efficient data manipulation.
- Apply dynamic memory allocation using `malloc`, `realloc`, and `free`.
- Manage persistent data using text and binary file handling.
- Develop modular applications using user-defined functions.
- Handle memory and file-related errors gracefully.

> **Note:** All programs are implemented in **C** using concepts covered in the assignment, with each solution organized in a separate source file.
