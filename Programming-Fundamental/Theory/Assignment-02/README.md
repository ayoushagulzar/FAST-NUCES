# Assignment 02 – Arrays, Functions & Bitwise Operations

This assignment focuses on building modular C programs using arrays, functions, loops, and bitwise operations to solve practical real-world problems.


## Topics Covered

- One-Dimensional Arrays
- Two-Dimensional Arrays
- Parallel Arrays
- Functions
- Function Parameters
- Menu-Driven Programming
- Loops
- Switch Statement
- Bitwise Operators
- Stack Implementation
- String Manipulation

## Tasks

### Question 01 – Book Inventory Management System
- Manage a bookstore inventory using parallel arrays and a menu-driven interface.

### Question 02 – Supermarket Inventory & Billing System
- Manage product inventory, shopping cart, customer information, and invoice generation.

### Question 03 – Power Grid Monitoring System
- Simulate sector status monitoring using a two-dimensional array and bitwise operations.

### Question 04 – Stack Implementation
- Implement stack operations using arrays and user-defined functions.

### Question 05 – Message Encoding & Decoding Utility
- Encode and decode text messages using string reversal and bit manipulation.

## Learning Outcomes

- Apply one-dimensional and two-dimensional arrays to solve real-world problems.
- Design modular programs using user-defined functions.
- Pass arrays and variables as function parameters.
- Develop menu-driven applications using switch statements.
- Perform bitwise manipulation for efficient data representation.
- Process and manipulate strings using character arrays.

> **Note:** All programs are implemented in **C** using concepts covered in the assignment, with each solution organized in a separate source file.
