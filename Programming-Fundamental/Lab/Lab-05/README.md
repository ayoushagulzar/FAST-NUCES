# Lab 05 – Nested Decision Structures

This lab introduces nested decision-making in C using conditional statements, logical operators, and the ternary operator to solve practical programming problems.

## Topics Covered

* Nested `if-else` Statements
* Logical Operators
* Modulus Operator
* Ternary Operator
* Decision Making

## Tasks

### Task 01 – Traffic Light System

Display the appropriate action based on the entered traffic light color.

### Task 02 – Age Category Classifier

Categorize a person's age into different life stages.

### Task 03 – Leap Year Checker

Determine whether a given year is a leap year.

### Task 04 – ATM Withdrawal Checker

Validate an ATM withdrawal request based on predefined conditions.

### Task 05 – Divisibility Checker

Check whether a number is divisible by both 3 and 5.

### Task 06 – Maximum of Two Numbers

Find the larger of two numbers using the ternary operator.

### Task 07 – Movie Rating Feedback

Display feedback based on the user's rating for a movie.

## Learning Outcomes

* Understand nested decision-making using `if-else`.
* Apply logical and relational operators effectively.
* Use the modulus operator for divisibility checks.
* Implement conditional expressions using the ternary operator.
* Solve real-world problems using decision structures.
