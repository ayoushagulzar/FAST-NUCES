# Lab 04 – Basic Decision Structures

This lab introduces decision-making in C using conditional statements. It focuses on solving problems with `if`, `if-else`, and `else-if` constructs.

## Topics Covered

* Decision Structures
* `if` Statement
* `if-else` Statement
* `else-if` Ladder
* Relational Operators
* Logical Operators
* Character Handling

## Tasks

### Task 03 – Character Classification

Determine whether an entered character is an alphabet, digit, or special character.

### Task 04 – Eid Shopping Discount Calculator

Calculate the discount and final payable amount based on the shopping cost.

### Task 06 – Loan Eligibility Checker

Determine loan eligibility based on the user's credit score.

### Task 07 – Time-Based Greeting

Display an appropriate greeting according to the entered time.

## Learning Outcomes

* Understand decision-making using conditional statements.
* Apply relational and logical operators.
* Solve real-world problems using conditional logic.
* Develop logical thinking through branching structures.
