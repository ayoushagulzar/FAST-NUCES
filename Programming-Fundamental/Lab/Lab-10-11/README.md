# Lab 10 & 11 – Introduction to Recursion and Structures in C

These labs introduce recursion, structures, nested structures, storage classes, and file handling in C through practical programming exercises.

## Topics Covered

* Recursion
* Structures
* Nested Structures
* Arrays of Structures
* Constants
* Static Variables
* File Handling

## Tasks

### Task 01 – Sum of Digits

Calculate the sum of digits of a number using recursion.

### Task 02 – String Reversal

Reverse a string using a recursive function.

### Task 03 – Flight Management System

Manage flight information and seat bookings using structures.

### Task 04 – Movie Management System

Store, search, and display movie information using structures.

### Task 05 – Sports Team Management

Manage team and player information using nested structures.

### Task 06 – Employee Payroll System

Calculate and display employee salaries using nested structures.

### Task 07 – Vowel Counter

Count the number of vowels in a string using recursion.

### Task 08 – Function Call Counter

Use constants and static variables to perform unit conversion and track function calls.

### Task 09 – Recursive Linear Search

Search for an element in an array using recursion.

### Task 10 – Palindrome Checker

Determine whether each word in a 2D array is a palindrome.

### Task 11 – Word Search

Search for a word in a 2D character array.

### Task 12 – File Statistics

Count the number of characters, words, and lines in a text file.

### Task 13 – File Content Deletion

Delete all contents of a file and verify that it is empty.

### Task 14 – Execution Logger

Append the current timestamp to a log file each time the program runs.

### Task 15 – File Merger

Merge the contents of two files into a third file.

## Learning Outcomes

* Understand recursive problem-solving techniques.
* Design programs using structures and nested structures.
* Work with arrays of structures.
* Use constants and static variables effectively.
* Perform file input and output operations in C.

> **Note:** The original lab questions are included as comments at the beginning of each source file for reference.
