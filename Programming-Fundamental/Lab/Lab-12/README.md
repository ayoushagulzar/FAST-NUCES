# Lab 12 – Introduction to Dynamic Memory Allocation (DMA)

This lab introduces dynamic memory allocation in C using `malloc()`, `realloc()`, and `free`. It focuses on efficient memory management for arrays, matrices, and strings.

## Topics Covered

* Dynamic Memory Allocation (DMA)
* `malloc()`
* `realloc()`
* `free()`
* Dynamic Arrays
* Dynamic Matrices
* Dynamic Strings

## Tasks

### Task 01 – Matrix Multiplication

Dynamically allocate memory for matrices and calculate their product.

### Task 02 – Dynamic Array Resizing

Resize an integer array using `realloc()` and update its elements.

### Task 03 – Dynamic String Sorting

Store strings of varying lengths dynamically and sort them alphabetically.

### Task 04 – Monthly Sales Management

Manage and extend sales data dynamically while calculating total sales.

## Learning Outcomes

* Understand dynamic memory allocation in C.
* Allocate and deallocate memory using `malloc()` and `free()`.
* Resize allocated memory using `realloc()`.
* Manage dynamic arrays, matrices, and strings efficiently.
