# Lab 07 – Introduction to One-Dimensional Arrays with Loops

This lab introduces one-dimensional arrays in C and demonstrates how to process array data using loops, functions, and string handling techniques.

## Topics Covered

* One-Dimensional Arrays
* Array Traversal
* Functions with Arrays
* String Handling
* Scanset
* Searching Algorithms

## Tasks

### Task 01 – Sum of Array Elements

Calculate the sum of all elements in an array.

### Task 02 – Reverse Array

Display the elements of an array in reverse order.

### Task 03 – Duplicate Element Finder

Identify the elements that occur more than once in an array.

### Task 04 – Remove Numeric Characters

Discard numeric characters from a string using a scanset.

### Task 05 – Whitespace Counter

Count the whitespace characters in a string using a scanset.

### Task 06 – Array Merger

Merge two arrays into a single array.

### Task 07 – Linear Search Function

Search for an integer in an array and return its index.

## Learning Outcomes

* Understand one-dimensional arrays in C.
* Traverse and manipulate arrays using loops.
* Implement basic searching techniques.
* Use functions with arrays.
* Apply scansets for string processing.
