# Lab 08 – Introduction to N-Dimensional Arrays with Nested Loops

This lab introduces multidimensional arrays in C and demonstrates how to process them using nested loops for pattern generation, matrix operations, and numerical computations.

## Topics Covered

* Nested Loops
* Two-Dimensional Arrays
* Three-Dimensional Arrays
* Matrix Operations
* Pattern Printing
* Prime Numbers

## Tasks

### Task 01 – Right-Angled Triangle Pattern

Generate a right-angled triangle using nested loops.

### Task 02 – Multiplication Table

Display the multiplication table of a given number.

### Task 03 – Matrix Addition

Add two 2×2 matrices using nested loops.

### Task 04 – 3D Array Display

Initialize and display a 2×2×2 three-dimensional array.

### Task 05 – Matrix Transpose

Display the transpose of a two-dimensional array.

### Task 06 – Saddle Point Finder

Find the saddle point(s) in a 3×3 matrix.

### Task 07 – Prime Number Generator

Generate prime numbers within a given range using nested loops.

## Learning Outcomes

* Understand multidimensional arrays in C.
* Traverse arrays using nested loops.
* Perform basic matrix operations.
* Solve numerical and pattern-based problems.
* Apply nested loops to multidimensional data.
