# Lab 06 – Introduction to Iterative Structures (Loops)

This lab introduces iterative programming in C using loops. It also covers mathematical library functions and bitwise operators through practical problem-solving exercises.

## Topics Covered

* `for` Loop
* `while` Loop
* Nested Loops
* Loop Control
* Math Library Functions
* Bitwise Operators

## Tasks

### Task 01 – Repeated User Input

Continuously accept and accumulate user input until zero is entered.

### Task 02 – Multiplication Table

Generate the multiplication table of a given number.

### Task 03 – ATM Withdrawal System

Simulate ATM withdrawals while maintaining the available balance.

### Task 04 – Armstrong Number Checker

Determine whether a given number is an Armstrong number.

### Task 05 – Factorial Calculator

Calculate the factorial of a given number.

### Task 06 – Number Reversal

Reverse the digits of a positive integer.

### Task 07 – Coin Change Calculator

Determine the minimum number of coins required for a given amount.

### Task 08 – Earthquake Magnitude Calculator

Calculate earthquake magnitude using `log10()`.

### Task 09 – Cinema Ticket Cost

Calculate the rounded-up total ticket cost using `ceil()`.

### Task 10 – Future Value Calculator

Compute the future value of an investment using `pow()`.

### Task 11 – Building Shadow Length

Calculate the shadow length using the `tan()` function.

### Task 12 – Even or Odd Checker

Determine whether a number is even or odd using bitwise operators.

### Task 13 – Set Bit Counter

Count the number of set bits in a binary representation.

### Task 14 – Multiplication Using Left Shift

Multiply a number using left shift operations.

### Task 15 – Swap Using XOR

Swap two integers using the XOR operator.

## Learning Outcomes

* Implement iterative solutions using `for` and `while` loops.
* Solve numerical problems using loops.
* Apply mathematical library functions in C.
* Understand and use bitwise operators.
* Develop efficient solutions for common programming problems.

> **Note:** The original lab questions are included as comments at the beginning of each source file for reference.
