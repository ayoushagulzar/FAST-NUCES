# Lab 03 – Introduction to C Programming Language

This lab introduces the basics of the C programming language. It focuses on user input/output, conditional statements, `switch` statements, escape sequences, and formatted output using precision specifiers.

## Topics Covered

* C Program Structure
* Variables & Data Types
* User Input and Output
* Conditional Statements (`if-else`)
* `switch` Statement
* Arithmetic Operations
* Escape Sequences
* Floating-Point Precision

## Tasks

### Task 01 – Multiple of Three

Determine whether a number entered by the user is a multiple of 3.

### Task 02 – Simple Calculator using `switch`

Perform an arithmetic operation based on the operator entered by the user.

### Task 07 – Input and Output in C

Accept the user's name and age, then display a formatted greeting.

### Task 08 – Simple Calculator

Take two integers as input and display their sum, difference, product, and quotient.

### Task 09 – Escape Sequences Practice

Print formatted text using escape sequences such as `\t` and `\n`.

### Task 10 – Precision in C

Display a floating-point number with 2 and 6 decimal places using `printf` precision specifiers.

## Learning Outcomes

* Understand the basic structure of a C program.
* Work with variables and basic data types.
* Accept user input using `scanf()`.
* Display output using `printf()`.
* Implement decision-making using `if-else` and `switch`.
* Use escape sequences for formatted output.
* Format floating-point values using precision specifiers.
