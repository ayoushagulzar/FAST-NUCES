# Lab 09 – Introduction to Functions and Pointers

This lab introduces functions and pointers in C through practical applications involving arrays, pointer manipulation, and generic programming concepts.

## Topics Covered

* Functions
* Function Parameters
* Pointers
* Pointer Arithmetic
* Arrays and Pointers
* Two-Dimensional Arrays
* Generic Functions (`void *`)

## Tasks

### Task 01 – Hospital Bed Management

Manage hospital bed occupancy using a 2D array and pointers.

### Task 02 – Bank Account Management

Perform balance updates and calculate the average balance using pointers.

### Task 03 – Vowel Replacement

Replace all vowels in a 2D character array with `*`.

### Task 04 – 2D Array Search

Search for an element in a 2D array using pointers.

### Task 05 – Generic Data Display

Display different data types using a generic `void *` function.

### Task 06 – Student Attendance System

Calculate attendance percentages and identify students below the required threshold.

### Task 07 – Cricket Score Analyzer

Calculate total and average runs, and identify the highest scorer.

## Learning Outcomes

* Understand functions and parameter passing.
* Manipulate data using pointers.
* Work with one-dimensional and two-dimensional arrays.
* Apply pointer arithmetic for array processing.
* Implement generic functions using `void *`.

> **Note:** The original lab questions are included as comments at the beginning of each source file for reference.
