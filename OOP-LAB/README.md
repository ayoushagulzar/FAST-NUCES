# ☕ Object-Oriented Programming (OOP) Lab

This directory contains my solutions to the **Object-Oriented Programming (OOP) Lab** conducted during my **BS Software Engineering** coursework at **FAST – National University of Computer and Emerging Sciences (FAST-NUCES)**.

Each lab focuses on a specific Java concept through practical programming exercises. Every lab directory contains its own README describing the covered topics, objectives, and implemented tasks.

---

## 📚 Lab Overview

| Lab | Topics Covered |
|:---:|----------------|
| **Lab 01** | Java Basics & Classes |
| **Lab 02** | Operators, Control Structures, Loops & Math Library Functions |
| **Lab 03** | Classes & Objects |
| **Lab 04** | Constructors & Garbage Collection |
| **Lab 05** | Arrays, ArrayList & Static Keyword |
| **Lab 06** | Type Casting & Inheritance |
| **Lab 07** | Polymorphism, Method Overloading & Method Overriding |
| **Lab 08** | Abstract Classes & Interfaces |
| **Lab 09** | Containership & Nested Classes |
| **Lab 10** | Exception Handling |
| **Lab 11** | Generics & File Handling |
