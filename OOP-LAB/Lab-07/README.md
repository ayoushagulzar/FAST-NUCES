# Lab 07 – Polymorphism, Function Overloading & Function Overriding

This lab explores the concepts of **polymorphism**, **method overloading**, and **method overriding** in Java. The exercises demonstrate how different objects can share a common interface while providing their own implementations.

## Topics Covered

- Runtime Polymorphism
- Method Overriding
- Method Overloading
- Dynamic Method Binding
- Inheritance
- Parent Class References

## Tasks

### Task 01 – Animal Sounds
- Override `makeSound()` in `Dog`, `Cat`, and `Cow`.
- Demonstrate runtime polymorphism.

### Task 02 – Shape Area Calculator
- Implement `Circle`, `Rectangle`, and `Triangle`.
- Override the `area()` method for each shape.

### Task 03 – Payment Processing
- Implement different payment methods using method overriding.
- Demonstrate dynamic method dispatch.

### Task 04 – Employee Salary System
- Override `calculateSalary()` for different employee types.

### Task 05 – Notification System
- Implement different notification services using polymorphism.

### Task 06 – Transport Fare Calculator
- Calculate fares for different transport types.

### Task 07 – Restaurant Delivery System
- Calculate delivery fees for multiple restaurant categories.
- Demonstrate runtime polymorphism using parent class references.

### Task 08 – Smart Home Devices
- Store different smart devices in an array.
- Invoke overridden methods through polymorphism.

### Task 09 – Ride Sharing System
- Calculate fares for multiple ride categories.
- Demonstrate dynamic method binding.

### Task 10 – Course Grading System
- Implement different grading strategies using method overriding.

## Learning Outcomes

- Understand runtime polymorphism
- Override inherited methods effectively
- Apply dynamic method binding
- Design extensible class hierarchies
- Use parent class references with child objects
