# Lab 11 – Generics & File Handling

This lab explores Java Generics and File Handling by implementing generic classes, working with collections, reading and writing files, and managing file permissions.

## Topics Covered

- Generics
- Generic Classes
- Wildcards
- Comparable Interface
- ArrayList
- File Handling
- BufferedReader
- BufferedWriter
- File Permissions

## Tasks

### Task 01 – ArrayList File Storage
- Store user input in an ArrayList.
- Write the data to a text file.
- Read the contents back.
- Delete the file after completion.

### Task 02 – Student Registration System
- Create and manage a student information file.
- Register courses based on prerequisite requirements.
- Enforce credit hour limits.
- Read and display stored data.

### Task 03 – Generic Login System
- Create a generic authentication class.
- Validate user credentials against stored values.

### Task 04 – Generic Collection Operations
- Sort a generic collection.
- Calculate the total sum.
- Find the maximum value.
- Use Comparable and wildcard generics.

### Task 05 – File Permission Manager
- Create a confidential file.
- Assign file permissions based on user designation.
- Display the assigned access rights.

## Learning Outcomes

- Understand Java Generics
- Create generic classes and methods
- Work with bounded and wildcard generics
- Read from and write to text files
- Use buffered streams for file operations
- Manage basic file permissions
