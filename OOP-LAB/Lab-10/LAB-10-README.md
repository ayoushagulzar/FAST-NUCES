# Lab 10 – Exception Handling

This lab focuses on handling runtime errors gracefully using Java's exception handling mechanism. The exercises demonstrate how to validate user input, catch exceptions, and ensure programs continue to execute safely under unexpected conditions.

## Topics Covered

- Exception Handling
- Try-Catch Blocks
- Multiple Catch Blocks
- Input Validation
- Number Parsing
- Arithmetic Exceptions
- Custom Error Messages

## Tasks

### Task 01 – Average Calculator
- Calculate the average of a list of integers.
- Handle empty or null input.
- Skip invalid numeric values.
- Display an appropriate message if no valid integers exist.

### Task 02 – Factorial Calculator
- Calculate the factorial of a user-provided number.
- Validate numeric input.
- Handle negative values and integer overflow.

### Task 03 – Mathematical Operations
- Perform arithmetic operations on two user inputs.
- Handle invalid input and division by zero.

### Task 04 – Sentence Processing
- Validate sentence input.
- Handle empty input and sentences with insufficient words.
- Perform operations only on valid input.

## Learning Outcomes

- Understand Java exception handling
- Handle runtime errors using try-catch blocks
- Validate user input effectively
- Prevent application crashes through proper error handling
- Write more robust and reliable programs
