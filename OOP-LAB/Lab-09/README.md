# Lab 09 – Containership & Nested Classes

This lab introduces **containership**, **nested classes**, **inner classes**, and advanced object-oriented design concepts in Java. The exercises also explore interface default methods, static nested classes, anonymous classes, and conflict resolution.

## Topics Covered

- Containership
- Inner Classes
- Static Nested Classes
- Anonymous Classes
- Interfaces
- Default Methods
- Static Interface Methods
- Multiple Interface Implementation
- Method Conflict Resolution

## Tasks

### Task 01 – Smart Campus System
- Resolve default method conflicts.
- Implement an inner `Department` class.

### Task 02 – Online Learning Platform
- Design a hybrid course combining recorded and live sessions.

### Task 03 – Banking System
- Implement anonymous objects for fraud checking and auditing.

### Task 04 – Ride Sharing Application
- Implement multiple interfaces with a static nested class.

### Task 05 – Smart Vehicle System
- Model vehicles using containership and multiple interfaces.

### Task 06 – IoT Device
- Demonstrate interface default and static methods.

### Task 07 – Smart Healthcare System
- Implement patient management using containership and interfaces.

### Task 08 – Smart Home System
- Design appliances with nested settings and multiple control methods.

### Task 09 – E-Commerce Platform
- Implement order processing with nested invoice management.

### Task 10 – University Course System
- Design course management with nested and anonymous classes.

## Learning Outcomes

- Understand containership relationships
- Implement inner and nested classes
- Resolve interface default method conflicts
- Use anonymous classes effectively
- Apply advanced object-oriented design principles
