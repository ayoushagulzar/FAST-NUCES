# Lab 08 – Abstract Classes & Interfaces

This lab focuses on implementing **abstraction** in Java using **abstract classes** and **interfaces**. The exercises demonstrate how common behavior can be defined while allowing individual classes to provide their own implementations.

## Topics Covered

- Abstract Classes
- Abstract Methods
- Interfaces
- Interface Implementation
- Multiple Interface Implementation
- Runtime Polymorphism

## Tasks

### Task 01 – Payment System
- Implement different payment methods using a common interface.

### Task 02 – Smart Home Devices
- Design smart devices using interfaces for common operations.

### Task 03 – Shape Area Calculator
- Calculate the area of different shapes using abstraction.

### Task 04 – Online Learning System
- Model different user roles using abstract classes and inheritance.

### Task 05 – Smart Appliances
- Combine abstract classes and interfaces to model appliance behavior.

## Learning Outcomes

- Understand abstraction in Java
- Implement interfaces effectively
- Extend abstract classes
- Combine inheritance with interfaces
- Design flexible and reusable class structures
