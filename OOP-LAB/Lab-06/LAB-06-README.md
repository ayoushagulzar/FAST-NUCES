# Lab 06 – Type Casting & Inheritance

This lab introduces inheritance and type casting in Java by building class hierarchies and demonstrating code reuse through parent-child relationships.

## Topics Covered

- Inheritance
- Single Inheritance
- Multilevel Inheritance
- Method Overriding
- Runtime Polymorphism
- Upcasting
- Type Casting

## Tasks

### Task 01 – Employee Management System
- Implement inheritance using Employee and Manager classes.

### Task 02 – University Management System
- Demonstrate multilevel inheritance using Person, Student, and GraduateStudent.

### Task 03 – Permanent Employee Bonus
- Calculate and display employee bonuses using type casting.

### Task 04 – Banking System
- Compute interest using multilevel inheritance and type casting.

### Task 05 – Animal Sound System
- Override methods to demonstrate runtime polymorphism.

## Learning Outcomes

- Understand inheritance relationships
- Build multilevel class hierarchies
- Reuse functionality through inheritance
- Apply runtime polymorphism
- Perform explicit type casting
