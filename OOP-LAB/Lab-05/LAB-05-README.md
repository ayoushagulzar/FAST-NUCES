# Lab 05 – Arrays, ArrayList & Static Keyword

This lab explores data storage and manipulation using arrays, ArrayLists, and static members while solving practical object-oriented programming problems.

## Topics Covered

- Arrays
- Two-Dimensional Arrays
- ArrayList
- Object Collections
- Static Variables
- Static Methods
- Sorting & Searching

## Tasks

### Task 01 – Scholarship Management System
- Process student marks and determine scholarship eligibility.

### Task 02 – Patient Temperature Monitoring
- Analyze temperature records using a two-dimensional array.

### Task 03 – Online Store Orders
- Manage dynamic order data using an ArrayList.

### Task 04 – Student Record Management
- Store and process student objects dynamically.

### Task 05 – Bank Account Statistics
- Track total accounts and overall bank balance using static members.

## Learning Outcomes

- Work with one-dimensional and two-dimensional arrays
- Manage dynamic collections using ArrayList
- Store objects in collections
- Use static variables and methods
- Process and analyze datasets
