# Lab 04 – Constructors & Garbage Collection

This lab focuses on object initialization using constructors and explores constructor overloading, constructor chaining, copy constructors, and the fundamentals of garbage collection in Java.

## Topics Covered

- Constructors
- Constructor Overloading
- Constructor Chaining
- Copy Constructors
- Object Initialization
- Garbage Collection

## Tasks

### Task 01 – Library Book Management
- Implement multiple constructors with different initialization scenarios.
- Create objects using all available constructors.

### Task 02 – Employee Object Duplication
- Create a duplicate object using a copy constructor.
- Ensure changes to the duplicate do not affect the original object.

### Task 03 – Mobile Information System
- Assign default values using constructors.
- Reuse initialization logic through constructor chaining.
- Eliminate duplicate initialization code.

## Learning Outcomes

- Understand the purpose of constructors
- Implement constructor overloading
- Reuse constructors through constructor chaining
- Create independent object copies using copy constructors
- Understand the basics of Java garbage collection
